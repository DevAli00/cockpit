## Install

**macOS (Apple Silicon)**

```bash
brew tap devali00/cockpit https://github.com/DevAli00/cockpit
brew install --cask devali00/cockpit/cockpit
```

**Windows 10/11 (64-bit)** with [Scoop](https://scoop.sh):

```powershell
scoop bucket add cockpit https://github.com/DevAli00/cockpit
scoop install cockpit/cockpit
```

Or download a file below: the `.dmg` for Mac, the `-setup.exe` for Windows. The apps are not signed, so a
manual download needs one extra confirmation on first launch (see the README). `SHA256SUMS.txt` lists the
checksums of every file.
